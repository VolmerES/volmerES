## 👨‍💻 About Me

Embedded Systems Developer at **Proeti S.A.** (Madrid), a Spanish company building construction materials testing machinery, where I'm the sole in-house developer working across firmware, web interfaces and server infrastructure. Alongside that, I run **Volmer Studio**, my own freelance web development and digital consultancy, and I'm the technical lead and equity partner at **Winegang**, a wine-tasting subscription startup.

- 🔧 Building firmware (C), custom board control software (C++), and the PHP/JS/HTML/CSS web interface for Proeti's testing machines
- 🚀 Running **[Volmer Studio](https://www.volmer.es)** — web development, SEO/SEM and digital consultancy for small businesses
- 🍷 Technical lead & partner at **Winegang**, a wine-tasting subscription startup
- 🎓 Trained at **42 Madrid** — project-based software engineering
- 🌍 Multilingual: English 🇬🇧 | Español 🇪🇸 | Français 🇫🇷 | Galego
